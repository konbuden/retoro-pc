# X1 STAR SHOOTER v2

シャープX1風の配色とピクセル表現を使った、320×200のレトロシューティングゲーム。
HTML・CSS・JavaScriptはすべて `index.html` に内蔵しています。外部ライブラリ、画像、フォント、通信は不要です。

## 起動

`index.html` をブラウザで開き、画面下の **START** ボタンを押してください。
開発時はこのディレクトリで `python3 -m http.server 8000 --bind 0.0.0.0` を実行してHTTP配信することもできます。

## 操作方法

- PC：左右の矢印キーで移動、Spaceの長押しで連射、Enterで開始・ゲームオーバー後の再開。
- iPad：画面下の ◀ / ▶ を長押しで移動、FIRE を長押しで連射。移動と射撃の同時操作に対応。
- START / RESTART / RETRY：新しいゲームを開始します。途中のスコアはリセットされます。
- 敵を撃墜すると100点。敵の突破・自機への接触で残機が減り、3機を失うとゲームオーバーです。被弾直後は短い無敵時間があります。
- ハイスコアはゲームオーバー時にブラウザへ保存します。保存が制限されていてもプレイ可能です。
- 別タブへ移動中はゲーム進行を停止し、押しっぱなしの入力を解除します。

タッチ操作には Pointer Events と Canvas をサポートするモダンブラウザを使用してください。iPad Safari実機での確認結果は別途報告します。

## v2 の変更点

- `main` のオリジナル版 v1.0（`952401e7e52e5d7a185be4e0132d80a55ec92a68`）を保持し、改良は `feature/v2` のみで行います。承認なしで main にマージしません。
- X1のPSGをイメージした3声の矩形波BGM。オリジナルのループ曲をWeb Audioで合成するため外部音源は不要です（実機音源の厳密なエミュレーションではありません）。STARTまたは操作時に音声を有効化します。
- BGMボタンでオン・オフ。ゲームオーバー、非表示、ウィンドウのフォーカス喪失時に停止します。復帰時にブラウザが再生を制限した場合は操作ボタンを押すと再開できます。
- 開始時は自機3機（v1.0の既存仕様を維持）。画面上部に残機アイコンを表示します。
- 敵はピンクの直進型と黄色の蛇行型。撃墜の得点、難易度上昇、連射、無敵時間、ハイスコア、iPadの同時タッチ操作は維持します。

## 動作確認

ChromiumのローカルHTTPプレビューで、開始、BGMオン・オフ、敵2種の移動、撃墜得点、残機減少・無敵時間・ゲームオーバー、BGM停止、再出撃、ハイスコア保存を確認しました。iPadサイズのタッチエミュレーションで2本指による移動＋連射と入力解除を確認し、390px幅の表示にも横スクロールはありません。ブラウザのJavaScriptエラーはありませんでした。物理iPadのSafariでの動作・音の聴感確認は未実施です。


### スマホの音声再生

STARTやBGMボタンのタップで、音声の再開要求と短い無音バッファの開始を同時に行います。対応するSafariではAudio Sessionをplaybackに設定します。再生が中断された場合はBGMボタンが「BGM 再生」に変わり、1回のタップで再試行できます。スマホ側のメディア音量も確認してください。実機での可聴性は機種・ブラウザごとに確認が必要です。

## ゲームライブラリ

- 既存のSTAR SHOOTER：`index.html`（変更なし）。
- ゲーム選択画面：`games/index.html`。
- 「世界最恐の女」再現版：`games/sekai-saikyo-no-onna/index.html`。

新作はX1のHu-BASIC誌面画像を参考にしたブラウザ再現版です。ユーザーの補足に従い、PCエンジン「THE 功夫」をモチーフとしたカンフー対決を構成しました。原リストの完全移植ではなく、判読できない箇所は補完しています。詳細は [資料の読み取りと再現範囲](games/sekai-saikyo-no-onna/RECONSTRUCTION.md) を参照してください。操作は4/6または矢印で移動、1/Zでパンチ、2/Xでキック、3/Cでジャンプ。スマホでは画面のボタンを同時に長押しできます。

## CITY HIDE & SEEK

ゲーム選択画面 `games/` から、STAR SHOOTER・世界最恐の女・CITY HIDE & SEEK の3本を選べます。

- 新作：`games/city-hide-seek/`。見下ろし型の街でAIの鬼から60秒逃げ切れば勝利、接触で終了。
- 矢印キー・WASDまたは画面の方向ボタンで移動。EnterまたはSTARTで開始。
- Bを取ると鬼を5秒目隠し、Sを取ると4秒加速。建物は視線を遮ります。
- ゲーム内の「ゲーム一覧へ」からセレクタへ戻れます。
